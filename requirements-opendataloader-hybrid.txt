# Our patched docling fork (see Dockerfile.opendataloader-hybrid's comment above the
# apt-get git install) — combines three fixes: two upstream-PR'd (docling-project/docling
# #3933, #3938) and one not yet PR'd (containment-ratio cell dedup — fixes a duplicate-OCR-
# text bug where a small low-confidence cell fully contained in a larger higher-confidence
# one scored too low an IoU to be deduped). None released to PyPI yet.
#
# Pinned to the `combined-bugfix-fork` branch, not a fixed commit — deliberately floating,
# so a rebuild always picks up whatever's newest on that branch instead of needing this
# file edited every time a fix is added there. That's a different tradeoff than the
# opendataloader-pdf fork pin in the main Dockerfile (which pins a commit on purpose, for
# reproducibility) — this file trades that reproducibility for not having to hand-update
# the pin each time.
# Remove these two lines and let opendataloader-pdf's own docling[easyocr]>=2.91.0
# dependency resolve normally once all three fixes are merged and released.
#
# Two lines, not one, because upstream docling split into a "docling-slim" package
# (the actual code, built from the repo root) plus a "docling" meta-package (a
# dependency-only wheel at packages/docling/, just re-exporting docling-slim under
# the old name for backwards compatibility — see that subdirectory's pyproject.toml).
# A plain `docling[easyocr] @ git+...` install builds the *root* of the repo, which
# reports its real name (docling-slim) — pip then rejects it ("has inconsistent
# name: expected 'docling', but metadata has 'docling-slim'") rather than silently
# accepting a same-content package under the wrong name. So: install docling-slim
# from the repo root with the extra opendataloader-pdf actually needs, and install
# docling itself from the packages/docling subdirectory so pip has a same-named,
# same-version (2.118.0 both) distribution to satisfy opendataloader-pdf's
# `docling[easyocr]>=2.91.0` dependency line against.
docling-slim[feat-ocr-easyocr] @ git+https://github.com/ViolanteCodes/docling.git@combined-bugfix-fork
docling @ git+https://github.com/ViolanteCodes/docling.git@combined-bugfix-fork#subdirectory=packages/docling
opendataloader-pdf[hybrid]==2.5.0
